# Сверка DWG разделов СС (слаботочные системы)

Отдельный проект внутри репозитория: сверка двух версий чертежей разделов СС (v1 — базовая, v2 — актуальная). Не связан с CCTV-пакетами из `work/` и `tools/cctv/`.

Статус: **чертежи ещё не загружены**, работа не начата.

## Структура

| Путь | Назначение |
|---|---|
| `projects/ss_dwg_comparison/scripts/` | Скрипты инвентаризации, парсинга и сравнения |
| `projects/ss_dwg_comparison/reports/` | Отчёты (инвентаризация, итоговое сравнение) |
| `projects/ss_dwg_comparison/handover/` | Текущее состояние, решения, открытые вопросы |
| `data/drawings/ss_dwg_comparison/` | Рабочие КОПИИ DWG/DXF и промежуточные JSON |

## Правила

- Только чтение и анализ: исходные DWG не изменять, AutoCAD не запускать. Оригиналы остаются у владельца.
- Копии чертежей кладутся только в `data/drawings/ss_dwg_comparison/` (лимит 90 МБ на файл; приватность репозитория подтверждена маркером `data/drawings/.PRIVATE_REPO_CONFIRMED`).
- Имена файлов с суффиксом версии: `<имя>_v1.dwg`, `<имя>_v2.dwg`.
- Работа через ветку `agent/claude/...` и PR в `main`; в `main` напрямую не пушить.
- Перед коммитом: `python tools/repo_guard.py --staged`.
- В отчёты — только фактически найденные различия, без домыслов.

## Что нужно от владельца

1. Загрузить копии DWG v1 и v2 в `data/drawings/ss_dwg_comparison/`.
2. Указать, какие листы/разделы СС приоритетны.
3. Сообщить, есть ли ODA File Converter на рабочем ПК (DWG → DXF без AutoCAD); в облачной сессии он недоступен.
