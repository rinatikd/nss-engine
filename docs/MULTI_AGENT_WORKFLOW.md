# Общая работа Codex, Claude, Grok, Gemini и DeepSeek

## Область и разрешение

Пользователь разрешил Grok (xAI), Gemini (Google), DeepSeek и Claude читать код/инструкции приватного NSS для совместной работы и намерен подключать другие проекты. Это не разрешение передавать секреты, локальные чертежи, чужие чаты или произвольные папки. Каждый следующий проект включается с явным названием, репозиторием/папкой и задачей. API, кредиты, подписки и публичные туннели без отдельного разрешения не используются. Репозитории сохраняются приватными.

## Один протокол для всех участников

- GitHub Issue: Project, Task, Executor, Base branch/SHA, Allowed files, Acceptance criteria, Dependencies, Status. Отдельные задачи могут выполняться параллельно в непересекающихся областях.
- Основной ПК назначает исполнителя и интегрирует результат. Проверка Issue — организационное правило, не атомарная блокировка; при двойном назначении требуется разрешить конфликт до записи.
- Любой участник сначала читает AGENTS.md, docs/SOURCE_MAP.md, docs/PORTABLE_SKILLS.md и файлы конкретной задачи. Навыки читаются явно, если клиент их не обнаруживает автоматически.
- Для исходников фиксируется конкретный SHA. Повторно проверить базу перед применением патча. Снимок чата не заменяет fetch и не обновляется автоматически.
- Ответ: задача, база, реально прочитанные файлы, выводы с основаниями, proposed diff, реально выполненные и только предлагаемые проверки, ограничения, следующий шаг. Общий формат полей — docs/CLAUDE_HANDOFF_TEMPLATE.md; имя файла историческое, формат применим ко всем.
- Чат без инструментов записи возвращает предложение; Codex получает результат, проверяет и применяет его в отдельной ветке agent/<executor>/<task>, затем создаёт PR. Нельзя заявлять несуществующие commit/push/PR или исполнение AutoCAD/Revit.
- Инструмент с правом записи использует только назначенную область и свою ветку. Main не обновляется этим участником напрямую. Принятие проекта остаётся за пользователем.

## Проверенные возможности и текущие ограничения

| Участник | Канал | Что подтверждено | Что ещё не подтверждено |
|---|---|---|---|
| Codex CLI, основной ПК | Git + локальные инструменты | Первый push в main | Конкретное назначение следующих задач |
| Codex приложения, дополнительный ПК | Отдельный клон + Git + PR | Push/PR и CI; текущий клон C:/NSS_Engine/collaboration/nss-engine | Автоматический диспетчер |
| Claude Free | GitHub Integration | GitHub App установлен; проверка разрешает cloud sessions | Обычный чат не подтвердил чтение файлов: лимит сообщений; Code требует платного плана |
| Grok | GitHub из каталога коннекторов | Официальная документация описывает GitHub; вкладка открыта | Вход, объём OAuth, чтение NSS, права записи |
| Gemini web | Import code / GitHub | Официальная документация поддерживает приватные репозитории; во вкладке виден аккаунт Google | Доступность импорта в текущем интерфейсе, привязка GitHub, чтение NSS |
| DeepSeek web | Обычный чат | Открыта страница входа | Вход, наличие прямого GitHub-коннектора, чтение NSS; API-интеграцию не считать возможностью бесплатного чата |

Статусы не означают, что участники уже выполняют задачи. Для каждого подключения нужны: вход, разрешение только на нужный репозиторий, пробное чтение известного файла с подтверждённым содержимым, тестовая задача и проверенный результат. Если OAuth требует доступ ко всем репозиториям или иное расширение прав, остановиться и показать пользователю точные разрешения перед подтверждением.

## Gemini: снимок вместо синхронизации

Google описывает импорт одного репозитория до 5000 файлов/100 MB в чат. Изменения после импорта не синхронизируются: повторить импорт нужной ветки и записать её SHA перед следующей задачей. Требуется Keep Activity; не менять настройку хранения активности автоматически ради подключения. Если функция недоступна, зафиксировать ограничение, не оформлять платную подписку.

## Grok и DeepSeek

У Grok сначала проверить GitHub в собственном каталоге и действительный объём OAuth. Не выдавать установленный коннектор за подтверждённое право создавать PR. Для DeepSeek сначала проверить интерфейс обычного чата: API key и интеграции агентских harness не являются доказательством встроенного GitHub-доступа. Если прямого канала нет, потребуется согласованный ограниченный пакет контекста; отсутствие ручного копирования пока не достигнуто. Не создавать обход через общий токен или публичный репозиторий.

## Будущее распределение задач

Автоматический диспетчер пока не реализуется. Выбор кандидата основывать на доступе к данным и инструментам, свободных лимитах, характере задачи и измеренных результатах. Не назначать модели постоянную специализацию по бренду. Для сравнения давать независимый одинаковый пакет/базу, измерять правильность, пропуски/ложные замечания, число правок, время, стоимость и принятие результата. Нативные CAD/BIM-проверки поручать только среде с доступным Autodesk.

Пока нет общей истории измерений, назначение делает основной агент/пользователь. При исчерпанном лимите участника не повторять запросы циклически; сохранять следующий шаг. Автоматизация браузера не считается официальным фоновым API или гарантированно работающим каналом обмена.
