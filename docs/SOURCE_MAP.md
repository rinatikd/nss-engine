# Карта исходников и границы первого коммита

Проверка 24.10.2026: до подготовки Git в корне проекта не было `.git`; во время обхода каталогов исходников вложенные Git-репозитории не обнаружены. Старые рабочие копии, результаты и поставочные ZIP сохранены на основном ПК. Код не перемещался и не удалялся. Создан новый Git-репозиторий в корне.

Приоритет текущей рабочей базы установлен по составу кода и существующим отчётам, а не только по дате каталога. `work/NSS_TKK_Editor_v0.2/source/TkkEditor.csproj` объявляет net8.0-windows/x64, версию 0.2.3 и включает CctvCommands.cs; рядом актуальный модуль CCTV. `work/NSS_AutoDebug_v0423/README.md` описывает диагностическую v0.42.3 и её текущие ограничения. Более старые NSS_Engine_v0.42_Release, NSS_RealDXF и копии из output остаются локально; их историю выпусков не выдаём за Git-историю.

В первый коммит входят код, исходники тестов/сценариев, существующие текстовые инструкции выбранных модулей, каталог камер и переносимые навыки. Реальные snapshot/result/issues JSON и evidence намеренно не включены. Тесты test_editor_fixture и test_native_fixture и один метод test_diagnostics с частным снимком не входят в portable test runner. Их код сохранён, но для запуска требуются локальные входы.

`AUTONOMOUS_PROGRESS_RU.md`, graphify-out, EDITOR_STATUS и отчёты из output — локальная память и результаты, не единый актуальный API/релиз. В частности, старые инженерные замечания не означают, что пользователь принял проект.

СВН v09: штатный вариант 34 ТВ/11 шкафов; угловое предложение 47 ТВ/12 шкафов не согласовано. Кронштейны ТВ — на ограждении снаружи; ВН/шкафы — на существующих опорах освещения. Внутренние 29 камер и блоки КПП/ЦОУ — отдельные стадии. Файлы рабочих чертежей и общая смета не опубликованы.

Секреты проверяются по именам/типам файлов и высокодостоверным текстовым шаблонам; это не математическое доказательство отсутствия всех возможных секретов. Подозрительные значения никогда не печатаются в отчёт. Перед публикацией новой группы данных требуется отдельная проверка.

Главный ПК не должен терять локальные данные после клонирования/публикации: игнорирование не удаляет файлы. Доступ к удалённой истории из sandbox на этапе подготовки отсутствовал. Скрипт первого push повторно проверяет origin в обычном PowerShell и не перезаписывает имеющуюся ветку.

Верхнеуровневые авторские Python-скрипты work также сохранены в Git как исходный инструментарий. Они не запускаются CI автоматически и могут ссылаться на локальные инженерные входы/старые каталоги выпусков. Исходники сборок и тестов не перемещены.

При проверке синтаксиса обнаружен повреждённый первый символ в старом work/build_cctv_package_v06.py. Файл не изменён и не удалён, но исключён из первого коммита; актуальные построители v07/v09 сохранены отдельно.
