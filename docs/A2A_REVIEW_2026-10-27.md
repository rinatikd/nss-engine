## Границы результата

- JS fake CLI E2E не доказывает реальное выполнение Codex или Claude. Настоящий Codex0.163.0 проверен только через безопасный parse-only --help.
- JS HTTP adapter имеет собственный контракт; нативного Anthropic API/Claude Code CLI adapter здесь нет.
- Windows VM, эффективный набор инструментов и изоляция чтения/сети не подтверждены. CODEX_DISABLED в рабочем Windows Bridge не изменялся.
- Реальный Ollama/MCP E2E выполняется [отдельным CI run](https://github.com/rinatikd/nss-engine/actions/runs/40517940935). Пока его итог не проверен, это не PASS.
- Подключение ChatGPT custom MCP app/Tunnel не подтверждено: среда по-прежнему не имеет tunnel ID/runtime key; текущая spec_revision=2 содержит только package manager egress presets. Опубликованный код не создаёт приложение в другом аккаунте ChatGPT автоматически.
- MCP COMPLETED означает AI-review, а не принятие человеком или публикацию в GitHub.
