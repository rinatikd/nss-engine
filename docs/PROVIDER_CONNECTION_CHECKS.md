# Проверки подключений — 2026-10-24

## Grok: чтение подтверждено

Пользователь сам завершил GitHub OAuth. В интерфейсе Grok виден статус «Подключено». Полный список прав на экране согласия агент не наблюдал; права записи и охват остальных репозиториев неизвестны и не тестировались.

На ограниченный read-only запрос Grok вернул main SHA `79a53fec612b80c1c6cf3afff6c39931f5939675`, сведения о TKK/CCTV версии 0.2.3 и отдельной AutoDebug 0.42.3, а также правило веток и repo_guard из AGENTS.md. SHA и детали совпали с локальным клоном. Это подтверждает получение непубличного содержимого NSS, но не push/PR.

Первая задача: ревью docs/MULTI_AGENT_WORKFLOW.md и GEMINI.md из head `a3f6a2f1f0a953168de4a296716815ace89a0b59`, base PR2 `e95e0d4fd3ff4228e0d01ccbcef4a60214e57082`. В интерфейсе показано использование GitHub-коннектора; ответ перечислил оба файла, SHA, три замечания и непроверенное. Запись в GitHub и запуск кода не поручались.

Проверка результата Codex: замечания в основном повторяют уже описанные ограничения подключения/квоты, не доказывают дефекты кода. Принято полезное уточнение: до назначения задачи проверять канал/лимит; без прямого канала использовать только явно перечисленный пакет контекста. Рекомендация требовать платный Claude Code для чтения нескольких файлов не принята: такого технического вывода из теста нет. По одному ревью нельзя ранжировать модели или назначать постоянную специализацию.

## DeepSeek: вход выполнен, прямой канал отсутствует в проверенной сессии

На прямой вопрос о возможностях обычный чат ответил, что инструмента авторизованного чтения приватного GitHub нет. README.md не прочитан, SHA не получен. В ответе использовался веб-поиск по возможностям продукта, несмотря на просьбу не подменять им авторизацию; результаты поиска не считаются доказательством доступа к проекту. Сторонние DSH-плагины не устанавливались, токены не передавались.

Резервный процесс — проверенный ограниченный пакет контекста, затем отчёт/предложение патча, проверка Codex и отдельный PR. Этот цикл ещё не выполнен; автоматическое обновление из GitHub не работает.

## Gemini: вход выполнен, согласие ожидается

После загрузки интерфейса найдено приложение GitHub: Настройки → Персональный ИИ → Подключенные приложения → GitHub. В карточке указаны импорт публичного/частного кода и вопросы по нему. Пользователю предложено открыть экран разрешений без подтверждения. Привязка GitHub, конкретный импорт и чтение NSS ещё не проверены. Настройка активности/подписки не менялась.

## Claude

GitHub App ранее проверен отдельно. Обычный чат остановился на лимите бесплатных сообщений; чтение кода и выполнение общей задачи ещё не подтверждены. При восстановлении лимита проверять существующий запрос, не создавать циклические повторы.

## Итог

На этом этапе Grok проверен для чтения и ограниченного ревью. Другие каналы не считать исполняющими агентами только по факту входа. Платные API, подписки, публичные репозитории и фоновые диспетчеры не включались. Нативные AutoCAD/Revit не запускались. Общий PR проверяет документацию, а не выдаёт разрешение на произвольную инженерную работу.
