# data/drawings — рабочие копии чертежей

Единственное место, где разрешены DWG/DXF (+ CSV/JSON рядом с ними). Оригиналы хранятся у владельца на компьютере.

Правила:
1. Сначала репозиторий делается **приватным** (Settings → General → Danger Zone → Change visibility). Потом владелец
   создаёт пустой файл `data/drawings/.PRIVATE_REPO_CONFIRMED`. Пока его нет, `tools/repo_guard.py` блокирует любой чертёж.
2. Лимит 90 МБ на файл (жёсткий лимит GitHub — 100 МБ), 500 МБ на всю папку.
3. Только DWG/DXF/CSV/JSON. RVT, архивы и т.п. запрещены и здесь.
4. В текстовых файлах (DXF/CSV/JSON) guard по-прежнему ищет секреты; бинарные DXF блокируются.
5. Правки агентов — в новых файлах с суффиксом (`_v2`, `_cctv`), оригинальную копию не перезаписывать.
6. Если репозиторий снова станет публичным — сначала удалить папку из истории, а не просто из дерева.
