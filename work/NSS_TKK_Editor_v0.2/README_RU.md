# NSS TKK Editor v0.2.3

Редактор телефонной кабельной канализации для AutoCAD 2026 / Windows x64 / .NET 8. Отдельный комплект, пока не объединённый с NSS Engine v0.42.3. Python и зависимости включены.

Исправлено вмешательство автопересчёта в Undo/Redo. В полном AutoCAD проверен настоящий цикл Idle: добавление, перенос, удаление, Undo и Redo без ручного REBUILD. Повторное применение неизменённых аннотаций не записывает DWG; ручное повреждение подписи обнаруживается и исправляется при пересчёте. Сохраняются отчёты и переходы по всем 29 замечаниям. Пройдены 40 Python-тестов, 27 проверок C#↔Python и нативный сценарий редактирования, навигации, сохранения и повторного открытия. Внешний вид и печать ещё требуют просмотра инженером.

## Запуск

1. Полностью распакуйте ZIP в папку с доступом на запись. Перед переходом с любой предыдущей версии перезапустите AutoCAD: загруженную DLL нельзя обновить в том же процессе.
2. Запустите `PREPARE.cmd`. Он создаст `LOAD_NSS_TKK_EDITOR.lsp` для текущей папки. Повторяйте PREPARE после переноса комплекта.
3. Откройте `drawing/NSS_20_10_26_RESULT_NATIVE.dwg`. Это рабочая копия, построенная и сохранённая AutoCAD. Исходный DWG не используйте вместо неё.
4. Перетащите `LOAD_NSS_TKK_EDITOR.lsp` в окно рабочего чертежа. Если AutoCAD запросит доверие, разрешите загрузку именно этой DLL. Общие настройки безопасности не меняйте.
5. Дождитесь `NSS updated: wells=..., spans=..., warnings=...` и фазы `UPDATED` в `EDITOR_STATUS.json`. Затем сохраните рабочий DWG под новым именем. Если после сохранения шёл пересчёт, сохраните ещё раз после его завершения.

Нужен шрифт `isocpeui.ttf` (ФЭС) исходного чертежа. Единица координат — метр, INSUNITS должен быть Meters. Геометрия автоматически не масштабируется. Подмена загруженной DLL требует перезапуска AutoCAD.

В этом комплекте используется DWG: прежний подготовленный DXF из v0.1/v0.2 аварийно завершал проверенный AutoCAD Core Console до загрузки редактора. DWG построен на копии исходного файла без промежуточного преобразования подосновы в DXF. Исходный DWG не перезаписан.

## Команды

| Команда | Действие |
| --- | --- |
| `NSS_TKK_AUTO_ON` | Включает автоматический пересчёт после завершения команд редактирования. |
| `NSS_TKK_AUTO_OFF` | Отключает режим и останавливает текущий Python-процесс. Подписи сохраняются. |
| `NSS_TKK_UPDATE` | Ставит принудительный пересчёт в очередь; восстанавливает подписи даже без изменения геометрии. Режим автообновления сохраняется. |
| `NSS_TKK_CHECK` | Выполняет расчёт и проверку без транзакции аннотаций. Фаза `CHECKED` означает только проверку. Уже включённый автоматический режим продолжает действовать. |
| `NSS_TKK_REBUILD` | Выполняет расчёт и применение внутри явной команды, без ожидания Idle. Может занимать до двух минут; AutoCAD в это время ожидает завершения. |
| `NSS_TKK_STATUS` | Выводит подключённый чертёж, режим и состояние расчёта. |
| `NSS_TKK_ISSUES` | Пересчитывает список замечаний без изменения аннотаций; печатает номера, идентификаторы и путь к отчёту. |
| `NSS_TKK_ISSUE` | Запрашивает номер замечания, приближает его область и выделяет исходные объекты. |
| `NSS_TKK_NEXT_ISSUE` | Последовательно переходит по замечаниям; после последнего возвращается к первому. |

Фазы: `QUEUED` — ожидается запуск, `RUNNING` — расчёт или применение ожидает завершения, `CHECKED` — проверено без применения, `UPDATED` — аннотации применены либо подтверждено их полное совпадение с расчётом, `DISABLED` — режим выключен, `DISCARDED` — результат отвергнут, `FAILED` — ошибка. Только UPDATED подтверждает соответствие аннотаций расчёту. Сводные числа и предупреждения находятся в `details` статуса; полный результат — в папке задания.

## Правила редактирования

- Колодцы: копируйте существующие блоки на `NSS_TKK_WELLS_PROJECT` / `NSS_TKK_WELLS_ADDED_PROJECT` либо используйте CIRCLE. Поддерживаются блоки с CIRCLE/ELLIPSE непосредственно внутри определения. Копирование одной выноски не добавляет колодец.
- Трубы: LINE, ARC, LWPOLYLINE на `NSS_TKK_ROUTE_PROJECT`. Также распознаётся исходный слой `пр_телефонная_канализация`. Переносите необходимые концы труб вместе с колодцем. Редактор меняет только собственные аннотации и настройки, не строит геометрию за вас.
- КК-1…КК-24 закреплены. Правая ветвь после КК-21: 22=`260F43`, 23=`260DFB`, 24=`260E18`. Удалённый закреплённый номер резервируется; копия блока его не наследует. Настройки сохраняются внутри рабочего DWG после применения.
- Длины — вдоль трассы в плане. Пересечения без колодца не соединяются. Допуски: 1,1 м от центра колодца до оси; 0,2 м между свободными концами. Совпадение XY не доказывает вертикальное соединение.
- Колодец на участке делит его; удаление колодца объединяет участки в расчёте. Новые колодцы автоматически не вставляются. Свыше 120 м выдаётся `SPAN_OVER_120M`.
- Неоднозначное совпадение двух колодцев на одной станции с точностью 0,005 м останавливает расчёт с указанием объектов. Нулевые трассы, нечисловые координаты и повторные закреплённые номера отклоняются. Возврат участка в тот же узел отмечается `SELF_RETURNING_SPAN`, подпись такого участка автоматически не создаётся.
- Шрифт ФЭС, высота 1,25, маска фона 1,1. Расчёт учитывает трассы, колодцы и управляемые подписи; коллизии с остальной подосновой ещё не проверяются. Автопересчёт может изменить ручное положение подписей.

Рабочая DWG-модель: 112 выносок, 109 участков, закреплённые номера 1…24 сохранены. Остаются 29 предупреждений: 25 неоднозначных/свободных соединений и 4 справочных колодца вне распознанной сети. Нативная выгрузка использует центры реальных блоков и выборку дуг AutoCAD; она отличается от прежнего DXF-снимка, где было 28 предупреждений. Прежний снимок также сохранён как отдельный регрессионный пример. Расчётные проверки коллизий выносок дают ноль, их нативные размеры помещаются в зарезервированные области; печать и столкновения с остальной подосновой ещё не проверены.

## Диагностика и проверки

Для первого просмотра откройте `REVIEW_IN_DWG_RU.md`. Готовый отчёт по поставляемому DWG — `review/ISSUES_RU.md`, данные — `review/issues.json`. После изменения геометрии используйте `NSS_TKK_ISSUES`: предварительный отчёт относится к поставляемой модели.

Каждое замечание имеет стабильный идентификатор, исходные объекты, область WCS XY и ближайшие колодцы/трассы с расстояниями. Короткие остатки около колодца, свободные концы и концы рядом с другой трассой различаются в отчёте. Это диагностические признаки, без автоматического подтверждения соединений. Раздельные петли имеют отдельные места проверки. Перед переходом сохранённый расчёт сверяется с текущим отпечатком DWG; устаревший список пересчитывается.

`EDITOR_STATUS.json` записывается атомарно. `EDITOR_ERROR.txt` содержит последнюю ошибку и может оставаться после последующего успеха: текущее состояние определяйте по статусу. `Runs/<задание>/` содержит snapshot.json, result.json, issues.json, ISSUES_RU.md и потоки Python. Отчёты связаны с заданием и отпечатком. Устаревший результат, неправильные номера, стрелки, неполные подписи и некорректные области замечаний отклоняются до транзакции. При ошибке до commit прежние аннотации сохраняются. Превышение нативных метрик MLeader над зарезервированной областью также отменяет транзакцию.

`CHECK.cmd` запускает 40 автономных Python-тестов, включая диагностику, прежний DXF-снимок и выгрузку нативного DWG. `CHECK_FULL.cmd` дополнительно запускает 27 проверок C#↔Python; для него нужен установленный .NET 8 runtime с командой dotnet. Эти команды не запускают AutoCAD. Уже выполненные нативные проверки находятся в `evidence/native_scenario/` и `evidence/native_reopened/`. DLL для AutoCAD собрана; .NET SDK пользователю не требуется.

При повторном открытии DWG проверены все 24 закреплённых номера и геометрия 251 исходного объекта, для которых план меняет слои. Временный тестовый колодец в поставляемом DWG отсутствует. В полном AutoCAD один Undo восстановил удалённый колодец; после автоматического подтверждения подписей Redo снова удалил его. Команды CHECK/STATUS/ISSUES также сохраняли Redo в нативном сценарии с отключённым автообновлением. Команды перехода меняют вид AutoCAD: в нативной проверке это очищало Redo. Завершите нужное восстановление до навигации. Все 29 переходов проверены при обычном и повёрнутом виде, с выделением соответствующих объектов и без изменения захваченной геометрии. Эти проверки не заменяют просмотр чертежа инженером.

Для разработчика: `source/` — DLL, `engine/` — расчёт, `tests/` — проверки, `native/` — нативный smoke-сценарий. Команда сборки при установленном .NET SDK и AutoCAD 2026:

```powershell
dotnet build source/TkkEditor.csproj -c Release -o plugin -p:NuGetAudit=false
```

Аудит NuGet-уязвимостей этой командой не выполняется. Autodesk DLL в комплект не включены. `MANIFEST_SHA256.json` покрывает неизменяемую часть комплекта; диагностические evidence и генерируемый LISP исключены, поскольку меняются после запуска. Контрольная сумма всего ZIP лежит рядом с архивом.
