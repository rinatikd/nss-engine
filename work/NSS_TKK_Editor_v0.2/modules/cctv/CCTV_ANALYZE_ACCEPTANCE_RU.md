# NSS_CCTV_ANALYZE: приёмка в AutoCAD (выполняет владелец)

Ветка `agent/claude/cctv-f1-f2-process` (поверх `agent/chatgpt/cctv-m3-diagnostics`) проверена только чтением кода и CI-компиляцией против имитации API (если CI запущен).
Сборку реального `TkkEditor.csproj` и сценарии ниже нужно выполнить в обычном сеансе AutoCAD 2026 на тестовых копиях. Чертежи заказчика не использовать.

| № | Сценарий | Ожидается | Закрывает | Результат |
|---|---|---|---|---|
| 1 | Небольшой DXF и CSV, нормальный запуск | Сообщение «complete», рядом `*_CCTV_result.dxf`, нет файлов `*.tmp` | базовая работа | |
| 2 | Тяжёлый DXF (копия `садик сс.dxf`), ESC во время расчёта | «cancelled», `python.exe` исчез из диспетчера задач, нет результата и `*.tmp` | F1, F2 | |
| 3 | `NSS_CCTV_TIMEOUT_SECONDS=10` и тяжёлый DXF | Через ~10 с сообщение о превышении и stderr, процесс остановлен | F2 | |
| 4 | Уже есть `*_CCTV_result.dxf`, Overwrite, пустой CSV | Ошибка расчёта, старый результат не тронут | F3 | |
| 5 | Имя файла с `{` и `}` (например `план{1}.dxf`) | Сообщения показывают текст буквально | F4 | |
| 6 | Папка `runtime` временно переименована | Сообщение «CCTV module or packaged Python runtime is missing», без падения | F5 | |
| 7 | Окно AutoCAD во время расчёта | Перерисовывается, нет «Не отвечает» | F1 | |
| 8 | Клавиши и мышь в AutoCAD во время расчёта | Нет падений и повторного запуска команды (риск DoEvents) | риск правки | |
| 9 | Запрос дней: Enter, число, ESC | Enter = 30, число принимается, ESC выходит без запуска | F7 | |
| 10 | Единицы: Enter, Meters, Centimeters; затем реальный план в метрах | Enter = Millimeters; сектора и дальности соответствуют единицам плана | F6 | |
| 11 | Слои стен: пусто, одно имя, список через запятую, неверное имя | Пусто: предупреждение «every layer is treated as a wall»; верное имя: стены только с этого слоя; неверное: расчёт без стен без падения | F6 | |

Ограничения правки:
- ESC определяется по состоянию клавиши в системе: нажатие в другом окне тоже отменит расчёт.
- Таймаут по умолчанию 120 с, меняется переменной `NSS_CCTV_TIMEOUT_SECONDS` (10..3600).
- Единицы (`--unit`) и слои стен (`--layers`) теперь спрашиваются командой и передаются в `cctv_cli.py`. Пустой список слоёв означает «все слои считаются стенами» (с предупреждением).
- CI-компиляция (`CCTV_COMPILE_SMOKE`) пропускает вызов `DoEvents`; он проверяется только реальной сборкой.
- Если CI ругнётся на `DllImport` (предупреждение SYSLIB1054), заменить на `LibraryImport` или убрать опрос клавиши.
- Если сценарий 8 покажет проблему, цикл ожидания нужно переделать (расчёт в отдельном потоке с индикатором).
