# NSS_CCTV_ANALYZE: руководство пользователя

Команда AutoCAD `NSS_CCTV_ANALYZE` рассчитывает зоны обзора камер видеонаблюдения по оптике и порогам DORI (IEC 62676-4), учитывает стены с плана и считает объём архива.

**Что важно знать.** Расчёт плоский (2D) и ориентировочный: он не заменяет проектное решение и не учитывает перекрытия камер предметами и растительностью. Из плана читаются только отрезки, полилинии и 2D-полилинии (LINE, LWPOLYLINE, POLYLINE) из DXF в текстовом (ASCII) формате. DWG напрямую не читается, блоки и внешние ссылки не читаются. Исходный чертёж команда не меняет: результат пишется в новый файл.

## 1. Установка

1. Распакуйте комплект ZIP в постоянную папку (не в «Загрузки»), например `C:\nss\NSS_TKK_Editor_v0.2.3`. В папке должны быть `plugin`, `modules\cctv`, `runtime`.
2. Запустите в этой папке `PREPARE.cmd`.
3. Закройте AutoCAD полностью (все окна) и запустите заново.
4. Перетащите файл `LOAD_NSS_TKK_EDITOR.lsp` из папки комплекта в окно AutoCAD. Если AutoCAD спросит о доверии, разрешите только эту библиотеку (DLL), общие настройки безопасности не меняйте.
5. Сообщение `NSS editor error: Open the NSS RESULT working copy first…` при загрузке на пустом чертеже нормально.

Загрузку нужно повторять в каждом новом сеансе AutoCAD.

## 2. Подготовка данных

**План.** Сохраните план в DXF (ASCII) и убедитесь, что стены нарисованы отрезками или полилиниями. Запомните слои стен и единицы чертежа (мм, см или м).

**CSV камер.** Первая строка с заголовком, затем по строке на камеру; координаты в тех же единицах, что и план:

```csv
name,x,y,rotation_deg,model,focal_mm,height_m,tilt_deg,bitrate_mbps
VN-1.1,1000,1000,45,DS-2CD1143G2-I,2.8,3,20,4
```

`model` должна быть в каталоге `modules\cctv\catalog.csv`, а `focal_mm` в пределах `focal_min`–`focal_max` этой модели. Новую модель можно добавить в `catalog.csv` строкой с теми же колонками (`model, sensor_w_mm, sensor_h_mm, h_pixels, v_pixels, focal_min, focal_max, hfov_deg, vfov_deg, dori_d_m, dori_o_m, dori_r_m, dori_i_m, source`); данные берите из даташита производителя.

## 3. Запуск по шагам

1. В командной строке AutoCAD введите `NSS_CCTV_ANALYZE`, Enter.
2. Выберите файл плана (DXF), затем файл камер (CSV).
3. Если рядом уже есть `<имя плана>_CCTV_result.dxf`, команда спросит `Output already exists [Overwrite/Cancel] <Cancel>:`. Выберите вариант мышью или введите `Overwrite` целиком на английской раскладке. Enter оставляет `Cancel`.
4. `Archive retention days <30>:` срок хранения архива в днях, Enter = 30 (допустимо 1–3650).
5. `Drawing units [Millimeters/Centimeters/Meters] <Millimeters>:` единицы вашего плана. Выбирайте вариант мышью или вводите слово целиком: `Millimeters` и `Meters` начинаются на одну букву. После выбора команда пишет `Drawing units: … (1 drawing unit = … m)`. Проверьте, что единица верная; если нет, нажмите ESC и запустите заново.
6. `Wall layers, comma-separated (Enter = all layers):` слои стен через запятую, например `A-WALL,Стены`. Регистр не важен. Вводите руками, не вставкой из буфера. Пустой ввод означает, что стенами считаются все слои плана (команда предупредит об этом).
7. Команда напишет `CCTV calculation started. Press ESC to cancel (timeout N s).` и начнёт расчёт. Типичный расчёт занимает секунды; большие планы с десятками камер занимают десятки секунд.

## 4. Результат

- Файл `<имя плана>_CCTV_result.dxf` рядом с планом. Слои: `CCTV_CAM` (камеры), `CCTV_FOV` (поле зрения), `CCTV_DORI` (зоны Detect/Observe/Recognize/Identify), `CCTV_TEXT` (подписи), `WALLS_REF` (стены, учтённые в расчёте).
- В командной строке: по строке на камеру (модель, фокус, горизонтальный угол, высота, дальности DORI, битрейт, ТБ/сутки) и итог `Архив N сут (+20%): X ТБ`.
- Откройте результат отдельно (команда `OPEN`), не вставляйте в рабочий чертёж без проверки.

## 5. Отмена и таймаут

- ESC во время расчёта останавливает его: `CCTV calculation cancelled. No result was written.` Старый результат не меняется. ESC учитывается, пока активно окно AutoCAD.
- Если расчёт идёт дольше 120 секунд, он останавливается с сообщением об ошибке `NSS_CCTV_ANALYZE failed: CCTV calculation exceeded N seconds.`
- Изменить лимит: переменная среды Windows `NSS_CCTV_TIMEOUT_SECONDS` (10–3600 секунд). Задайте её в «Переменные среды» Windows и перезапустите AutoCAD (процессы читают переменные при старте).

## 6. Сообщения об ошибках

| Сообщение | Причина | Что делать |
|---|---|---|
| `NSS_CCTV_ANALYZE failed: CCTV module or packaged Python runtime is missing. Expected: <путь>` | Нет папки `runtime` или `modules\cctv` рядом с папкой `plugin` | Восстановите папки из ZIP; не переносите `plugin` отдельно |
| `NSS_CCTV_ANALYZE failed: CCTV calculation failed (exit N): …` | Ошибка в расчёте; причина в тексте после двоеточия | Прочитайте текст; типичные причины ниже |
| …`camera CSV contains no camera rows` | В CSV только заголовок | Добавьте строки камер |
| …`<камера>: фокус вне диапазона модели` | `focal_mm` вне диапазона модели в каталоге | Исправьте фокус или модель |
| …`KeyError: '<модель>'` | Модели нет в `catalog.csv` | Проверьте написание модели или добавьте её в каталог |
| …`output DXF cannot overwrite a source input` | Результат совпал бы с планом, CSV или каталогом | Не выбирайте как план файл `…_CCTV_result.dxf`; переименуйте входной файл |
| …`CCTV calculation exceeded N seconds.` | Превышен таймаут | Упростите план (меньше слоёв и линий) или увеличьте `NSS_CCTV_TIMEOUT_SECONDS` |
| …`The calculation succeeded, but the result could not replace <файл> …` | Старый результат открыт в другой программе или защищён от записи | Закройте файл и запустите снова |
| `No wall layers given: every layer in the plan is treated as a wall.` | Слои стен не указаны (предупреждение) | Если стены на отдельных слоях, перезапустите и укажите их |
| `Неправильное ключевое слово` | Введено не то слово в запросе с вариантами | Выберите вариант мышью или введите слово целиком, латиницей |
| `Неизвестная команда NSS_CCTV_ANALYZE` | Плагин не загружен | Повторите шаг 4 установки |

## 7. Вопросы и ответы

**Нужен ли DWG?** Нет. Сохраните план как DXF (ASCII); результат тоже DXF.
**Что будет с моим чертежом?** Ничего: команда читает файл плана с диска и пишет новый файл.
**Что, если указать не те единицы?** Дальности и сектора окажутся в 1000 раз больше или меньше. Проверяйте строку `Drawing units: …` до начала расчёта.
**Можно ли запускать расчёт на плане, открытом в AutoCAD?** Выбирайте сохранённый DXF-файл; несохранённые изменения в расчёт не попадут.
**Где хранятся модели камер?** В `modules\cctv\catalog.csv`.
