# СВН-модуль для AutoCAD 2026 — карта проекта (обновлено 2026-10-20)

## Модули (/home/claude/cctv)
- cctv_core.py — оптика/DORI (Lens с hfov_override_deg), лучи и стены, архив, чтение ASCII DXF (LINE/LWPOLYLINE/POLYLINE), запись DXF R12 (блок CCTV_CAM с ATTDEF), каталог, xlsx.
- cctv_cli.py — запуск по plan.dxf + cameras.csv; catalog.csv — модели с hfov по даташиту и источником.
- extract_light.py — выжимка слоёв из большого DXF (потоковая) + статистика слоёв/блоков.
- run_sadik2.py — прогон на реальном проекте (детский сад, Астана): сопоставление подписей ВН-n с «уголками».
- test_cctv_core.py — 8 тестов (HFOV, PPM, DORI, стены, архив, DXF round-trip).

## Знания о чертежах заказчика
- DXF: AC1032/AC1027, UTF-8 (в заголовке ANSI_1251), единицы — мм. Большой объём — блоки (48 из 64 МБ), не стены.
- Камеры на слое КАМЕРА: блоки «купольная цветная вк» / «камера уличная» БЕЗ атрибутов; зеркальные при отриц. масштабе X (направление +180°).
- У каждой камеры «уголок»: LWPOLYLINE из 3 вершин на слое КАМЕРА; прямой угол = камера, биссектриса = направление.
- Подписи камер — TEXT ВН-n.m на слое «Размеры и аннотации». На 1 этаже 20 камер: ВН-1.6…1.24 и ВН-2.1; ТД-1.2/1.3 — терминалы СКУД.
- Архитектурная подложка — отдельный файл «Садик СС 1 этаж.dxf»; слои препятствий: СТЕНЫ НАРУЖНЫЕ/ВНУТРЕННИЕ/НЕСУЩИЕ/ПЕРЕГОРОДКИ, НЕСУЩИЕ КОЛОННЫ, ДВЕРИ, ОКНА, ВИТРАЖ, ПАНЕЛИ ВИТРАЖА. Общие координаты с файлом камер.
- Модели по ведомости: купольные DS-2CD1143G2-I (2560×1440, HFOV 99°), уличные DS-2CD2043G2-I (2688×1520, HFOV 103°): ВН-1.9, 1.10, 1.20–1.24, 2.1. Архив: 4 Мп, 15 к/с, H.265+, 720 кбит/с.
