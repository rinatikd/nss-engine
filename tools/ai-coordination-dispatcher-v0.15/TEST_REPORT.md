## Результат

**145 PASS, 0 FAIL, 0 SKIP** на Python 3.12.14 в Linux.
111 тестов поставленного v0.14 + 34 теста нового orchestration/local transport.
Реальных вызовов AI: **0**. Платных API-вызовов: **0**. Записей в GitHub: **0**.

Это проверенное локальное ядро координации, не работающая подключённая A2A-система.

этими тестами не подтверждаются.

## Исходный архив

Получены каталоги v0.9 и v0.14. README обоих начинается с v0.4, но v0.14 дополнительно
содержит историю v0.10–v0.14 и соответствующие модули/тесты. Называть их v0.2 оснований нет.
Общая основа совпадает побайтно, кроме ai_reviewer.py, README и test_v09.py;
в v0.14 добавлены модули последующих стадий.

Приложенная v0.9 содержит state.sqlite и response/rubric; из поставки v0.15 они исключены.
Загруженный Windows Python bytecode из __pycache__ не исполнялся и не включён в архив.
Оригиналы сохранены отдельно в a2a-review. Основной checkout nss-engine не менялся.

## Что реализовано и проверено

- `orchestrator.py`: submit/status/cancel/doctor/work/stage; SQLite WAL;
  отдельные executor/reviewer contexts, максимум две автоматические коррекции.
- Идемпотентность task-id и конфликт изменённых входов.
- Атомарное резервирование шага двумя параллельными workers.
- Продолжение review после перезапуска без повторного вызова исполнителя.
- Истечение lease, остановка после неопределённого результата и отсечение позднего ответа.
- Передача исходной задачи, рубрики, предыдущего ответа и замечаний в исправление.
- REJECT, предел итераций, карантин некорректного JSON и противоречивого одобрения.
- Подготовка outbox без публикации; mock-результат не принимается за настоящий.
- HTTP-тест через настоящий loopback test server: четыре отдельных POST,
  исправление по замечаниям и итоговое одобрение. Это fixture сервера, не Ollama/модель.
- Отказ следовать redirect локального endpoint и карантин усечённого ответа.
- Платный адаптер нового orchestrator заблокирован PAID_API_ALLOWED=False.
  Ни ключ в окружении, ни --live этот запрет не снимают.
- Суточное резервирование вызовов/оценочных токенов протестировано на fixtures.
  Эти тесты не доказывают денежный лимит или биллинг настоящего провайдера.

Команда тестов из каталога пакета:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -v -p 'test_*.py'
```

## Дополнительная CLI-проверка

Одна mock-задача выполнена четырьмя последовательными запусками `work --once`,
каждый в отдельном процессе:

`AWAITING_REVIEW → QUEUED → AWAITING_REVIEW → COMPLETED`, revision=1, attempts=4.

Другая mock-задача завершена непрерывным foreground worker `work --poll 0.1`.
После завершения worker остановлен SIGINT с ожидаемым exit=130. Фоновый сервис не оставлен.
Повторный submit даёт EXISTS; stage mock-ответа — BLOCKED. AST parse всех Python-файлов PASS.

## Что блокирует настоящую бесплатную работу

- Ollama executable отсутствует, GET `127.0.0.1:11434/api/tags` даёт ConnectionRefusedError.
- HTTPS-загрузка `https://ollama.com/install.sh` не выполнена: прокси отклонил CONNECT
  ответом 403. Текущая ограниченная политика не включает ollama.com.
- В черновике настроек среды сохранено только добавление `ollama.com` к разрешённым
  доменам. Остальные настройки и выбранные сетевые presets сохранены. Изменение ещё
  требует review/save/publish пользователем и не доказывает доступ в текущем runtime.
- Установщик не скачан и не исполнен. После открытия домена нужно проверить
  официальный дистрибутив, установить локальный runtime, определить необходимые
  домены загрузки выбранных моделей и выполнить реальную задачу executor/reviewer.
  Доступ к ещё не выявленным доменам не запрашивался наугад.
- Обычный ChatGPT-чат не подключён к очереди: аутентифицированный MCP/A2A endpoint
  и постоянный управляемый хост ещё не развёрнуты.

## Границы

Модели сейчас решают текстовые задачи, не получают shell/Autodesk и не изменяют код.
Windows Broker, Chrome Bridge, CODEX_DISABLED и trust store не менялись.
Исторические pilot/dispatcher сохранены для совместимости, их live-режимы использовать
при текущем запрете платных вызовов нельзя. Новый флаг политики не переписывает эти модули.
Стандартный A2A wire protocol, Agent Cards, streaming и удалённая аутентификация не реализованы.
Постоянный scheduler/service не установлен. GitHub publication и человеческая приёмка
остаются отдельными действиями.
