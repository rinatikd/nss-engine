# Оригинальные ресурсы нужны до сборки

В публичный комплект исходников не входят закрытые DWG/DXF, рамки, штампы и библиотека УГО. Этот README не является библиотекой блоков. Комплект содержит полные исходники preview.3 и не требует исходников или патча preview.2.

Перед сборкой восстановите сюда **собственную оригинальную папку `blocks`** из разрешённой локальной копии. Сохраните имена и содержимое оригиналов. Не заменяйте их пустыми файлами или искусственными чертежами.

`build.ps1` требует как минимум один непустой файл рамки из списка `ММХ_Штамп.dwg`, `MMH_Stamp.dwg`, `AGPT_Frame_A3.dwg`, `AGPT_Frame_A3.dxf` и один непустой исходный DWG УГО из списка `Садик_UGO_source.dwg`, `Садик.dwg`. Это проверка наличия, а не подтверждение формата CAD, полноты библиотеки, корректности символов или права их распространения. Для работы восстановите всю исходную библиотеку и проверьте её в AutoCAD.

После сборки папка `blocks` должна находиться рядом с `AGPT.dll` и `AGPT.InputCore.dll`. Не публикуйте восстановленные частные ресурсы вместе с исходниками.
