# Ресурсы CAD в дистрибутиве

В исходниках Git находятся код и инструкции. Частные DWG/DXF не коммитятся в репозиторий. Для рабочего дистрибутива они добавляются из предоставленной пользователем библиотеки отдельным этапом упаковки.

Проверяйте RELEASE_INFO.json: actualResourcesIncluded=true означает, что пакет действительно содержит CAD-файлы. В варианте with-blocks семь оригинальных файлов находятся в корневой blocks и рядом с DLL в Runtime/AutoCAD2025/blocks и Runtime/AutoCAD2026/blocks. actualResourcesIncluded=false означает комплект без частной библиотеки; один README не является блоками.

Состав: AGPT_Frame_A3.dwg/.dxf, AGPT_UGO.dxf, MMH_Stamp.dwg, MMX_ШТАМП.dwg, ММХ_Штамп.dwg, Садик_UGO_source.dwg. В исходном архиве несколько вариантов имени рамки/штампа имеют одинаковое содержимое; они не считаются разными проверенными штампами. Кириллические имена восстановлены; хеши исходного содержимого сохранены. Внутренний состав DWG и вставку УГО ещё нужно проверить в AutoCAD. SHX/TTF-шрифтов в переданном комплекте нет.

Для сборки из исходников восстановите собственные ресурсы перед build.ps1. Для локальной упаковки подготовьте внешнюю папку только с перечисленными семью CAD-файлами и передайте --blocks-root этой папки в ci/package_candidate.py. Все копии входят в SHA256SUMS.txt; RELEASE_INFO содержит отдельный инвентарь ресурсов. Дополнительные каталоги/инструкции в этой входной папке не принимаются.
