# Оформление альбома: сопоставление с предоставленными образцами

Просмотрены пять PDF: альбомы АГПТ трёх блоков МГИМО, АГПТ и АПС детского сада. Извлечены тексты всех страниц; визуально просмотрены листы структурной схемы/подключений, аксонометрии и спецификации АГПТ детского сада (страницы4,6,8 PDF). Визуальные ориентиры других комплектов: структурные листы9/13/11 и спецификации15/31/24 PDF МГИМО. PDF не включены в публичный пакет, их частные реквизиты и проектные количества не скопированы.

## До изменения

Команда аксонометрии выводила только ведомость участков. Спецификация брала только размещённые сущности, поэтому в модели с одним контуром не было строк оборудования. Фиксированная типовая структурная схема не отражала фактический состав зон.

## Preview.12

- Отдельные графические листы аксонометрической проекции по исходным XYZ-вершинам труб. Действительные Ду и длины, номера участков, высоты при наличии. Плоская сеть явно помечается: высотные отметки не заданы. Сохраняется отдельная ведомость расчётных участков. Схема не создаёт трубы по одному контуру помещения.
- Структура состава: зоны и фактически размеченные устройства, продолжения больших зон, отдельное отображение устройств без привязки к зоне. Штриховые ветви означают принадлежность зоне, а не проверенные кабельные или клеммные соединения. Для монтажной схемы соединений нужны реальные адреса, клеммы и проектные связи; они не извлекаются из площади комнаты.
- Спецификация: девять граф по композиции образца, читаемые переносы, продолжение длинных позиций на последующих строках/листах. Неизвестные коды/поставщик/масса не выдумываются. Количества только по размещённым размеченным элементам. Масса заправки ГОТВ не подменяет массу оборудования.
- Расчётная потребность в рабочих/резервных модулях — отдельная полностью пагинированная ведомость; не выдаётся за размещение и не прибавляется к спецификации.
- Отдельный лист состава исходных данных объясняет пустые разделы и даёт команды заполнения. Общая ведомость формируется после регистрации всех листов и продолжений.

## Проверка на AutoCAD

1. После обновления DLL выполнить AGPT_VERSION, AGPT_PROJECT, AGPT_ALBUM.
2. В общих данных проверить номера и количество листов; найти отдельные аксонометрию, спецификацию, структуру и расчётную потребность.
3. На модели только с зоной должны быть явные сообщения об отсутствии труб и размещённых устройств; ведомость потребности может содержать результат прототипного расчёта, спецификация размещения остаётся пустой.
4. На модели с размеченной сетью проверить, что проекция повторяет реальные ветви и высоты, подписи Ду/L соответствуют DWG, отсутствуют примерные трассы.
5. На длинной спецификации проверить продолжения и отсутствие потери позиций/текста; повторный AGPT_ALBUM заменяет прежний результат.

Сходство с предоставленными образцами — направление оформления, а не подтверждение полного визуального/нормативного соответствия. Облачный агент не запускал AutoCAD; нативная проверка новых листов не выполнена. Расчётная методика остаётся прототипной.
