# Проверка AGPT/APPT 1.1.0-preview.14 — 30.10.2026

## Изменения

По запросу пользователя: HFC-227ea, FH=0,011 м² и Tм=20°C при отсутствии явных данных. FH — редактируемое проектное допущение, не нормативный минимум. Явные значения и конфликты сохраняют приоритет. AGPT_OPENINGS изменяет FH с сохранением происхождения и пересчётом готовности зоны. Старые автоматические default температуры пересматриваются, ручные правки сохраняются.

Из предоставленной сборки перенесены идеи списка зон, обновляемых подписей, сохранения результатов, единой рабочей области листа и диагностики УГО. Код адаптирован к текущим классификации, транзакциям, общему расчёту и реальной геометрии. Демоданные, скрытый Vtr, K4, обрезание таблиц и ошибки рамок не перенесены. Исторические результаты записываются в отдельные CALC_SNAPSHOT_*: Hydro не получает их как текущую массу. Подписи исключаются из сборщиков и спецификации.

## Локальные проверки

317 тестов ядра: 0 ошибок, 0 пропусков (включая14 новых случаев FH). API25.1 компиляция успешна, 5 прежних предупреждений. После окончательной интеграции проверки повторяются. Проверка SHA256-инвентаря и репозиторный guard выполняются перед публикацией.

## CI

Linux/Windows core suite, PowerShell5.1 ресурсные и bundle/API/XML-проверки, компиляция API25.0/25.1 и упаковка по allowlist. Фактические результаты смотрите в соответствующем GitHub Actions запуске.

## Нативная проверка и ограничения

Операторские журналы preview.7/8 подтвердили загрузку, углы, высоту и прежние настройки; это не проверка preview.14. Журналы отражены в docs/AGPT_NATIVE_ACCEPTANCE_20261030.md. Облачный агент не запускал AutoCAD. Новые команды, повторное обновление/удаление подписей, оформление реальными блоками и визуальные наложения требуют проверки на AutoCAD. Численная инженерная методика, нормативная применимость, гидравлика и соответствие альбома эталонам не подтверждены. Прохождение тестов не является разрешением выпуска рабочей документации.

## Preview.11: временная объектная привязка

RoomBoundaryPicker сохраняет исходный OSMODE, задаёт16383 только внутри выбора и восстанавливает его в finally. Восстановление UCS выполняется даже при ошибке восстановления OSMODE. Это изменение CAD-адаптера; нативная проверка прилипания курсора и восстановления после Esc не выполнена.

## Preview.12: графические разделы альбома

336 тестов ядра прошли локально, 0 ошибок и пропусков: добавлены19 случаев проекции/XYZ/дуг/планарности/численных границ и пагинации/сохранения текста спецификации. Сборка API25.1 прошла с5 прежними предупреждениями до окончательной упаковки. Независимый обзор обнаружил наложение двух заголовков спецификации; дубль удалён. Новые графические листы внутри AutoCAD не проверялись; компиляция и чистые тесты не доказывают качество CAD-отрисовки.

## Preview.13: встроенный запрос реквизитов

Форма проекта вызывается перед сбором модели и перед транзакцией построения. Чтение и подтверждённая запись используют отдельные короткие транзакции. Отмена возвращает false и останавливает команду; уже валидные обязательные поля пропускают форму. После формы проверяется, что активный документ не сменился. Сохранённые, но неполные реквизиты также открываются для заполнения. Явные PROJECT-команды всегда открывают редактирование. Сборка API25.1 прошла с5 прежними предупреждениями. Нативная проверка модального сценария не выполнена; чистые тесты проверяют модель реквизитов, не окно AutoCAD.

## Preview.14: ресурсы и совместимость старых названий ГОТВ

380 тестов ядра прошли локально (0 ошибок/пропусков), включая известные варианты HFC/Хладон и отказ для иных веществ/смесей, поиск в корневой blocks и порядок путей. Шесть Python-тестов упаковки CAD-ресурсов прошли и добавлены в CI. Семь предоставленных CAD-файлов скопированы во внешнюю папку с восстановленными UTF-8-именами; исходные байты проверены по SHA256. Заголовки DWG AC1032 и EOF DXF проверены; это не проверка внутреннего состава DWG или оформления в AutoCAD.

Пакет with-blocks содержит21 CAD-копию (7файлов×3каталога); каждая входит в итоговый манифест. В Git не добавлялись бинарные ресурсы. Обычный CI пакет из репозитория остаётся без частной библиотеки и явно помечается actualResourcesIncluded=false. Шрифты GOST/SHX в исходной библиотеке отсутствуют; их наличие или право распространения не подтверждено. Нативная проверка вставки блоков и старой зоны из журнала не выполнена; исходное значение GOTV зоны в журнале не раскрыто.
