# Проверка standalone preview.5 — 30.10.2026

Ввод Cн, плотности, K4 и Vтр исключён из редактируемых параметров зоны. Cн и плотность берутся из явно выбранного профиля предоставленного проекта HFC-227ea с открыто указанным происхождением ProjectReference. Применимость к иным объектам и нормативным режимам не подтверждена. Старые отличающиеся значения требуют явного применения профиля.

K4 не назначается скрыто: дополнительное умножение из старого прототипа удалено из текущей схемы по предоставленному эталону, где такого множителя нет. Это изменение формулы, требующее инженерной проверки, а не утверждение нормативного значения коэффициента.

Vтр — результат суммы объёмов размеченных участков по текущим длинам, внутренним диаметрам и привязке к зоне. Ду не подменяет Dвн. AGPT_CALC и ALBUM используют общий сборщик. Изменение Ду требует повторного подтверждения Dвн; неизвестные параметры не заменяются default. Для старых труб предусмотрена AGPT_PIPE_DATA. Команда создания участка ограничена горизонтальной геометрией 2D-плана.

## Не подтверждено

Нативная загрузка AutoCAD, визуальная работа формы, реальные операции с DWG, построение и редактирование сети, качество чертежей и расчётная инженерная методика. Источники каталога — предоставленные проектные материалы, а не подтверждённая нормативная база всех юрисдикций. Прототип не готов к выпуску рабочей документации по одному факту прохождения тестов.

Гидравлический сборщик также использует текущие длины, исключает объекты альбома и проверяет исходные единицы. Пересчёт гидравлики не перезаписывает происхождение единиц: смена INSUNITS требует явной проверки свойств трубы.
