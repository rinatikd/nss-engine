# Проверка standalone preview.3 — 30.10.2026

Комплект перенесён из полных исходников preview.3, а не восстановлен из патча. Основные изменения preview.3: запрет повторного использования выходной геометрии в качестве исходных зон; замена только точно отмеченных объектов своего альбома в транзакции; сохранение объектов другой системы. Windows-скрипт дополнительно требует оригинальные непустые ресурсы рамки и УГО и отклоняет пустые известные имена, перекрывающие исправный ресурс.

## Дополнительный аудит установки

Обнаружены и исправлены два связанных дефекта: установщик всегда выбирал каталог 2026 и оставлял диапазон R25.0–R25.1 для одной сборки; проверка API допускала смешивание R25.0 и R25.1 между тремя ссылками. Теперь staging выбирает соответствующий каталог и точную версию хоста; смешанный набор отклоняется до сборки. Сериализация XML изменяет только staged-копию и сохраняет прежний механизм атомарной публикации. Чтение XML учитывает его объявленную кодировку; для обоих хостов проверяется сохранение кириллицы при записи и повторном чтении временного файла. Проверки helper-функций/XML не заменяют реальную установку и загрузку bundle.

Два независимых аудита исходников не обнаружили новых блокирующих дефектов в междокументных ObjectId, классификации исходной геометрии и транзакционной замене альбомов. Это результаты анализа кода, а не нативного исполнения.
