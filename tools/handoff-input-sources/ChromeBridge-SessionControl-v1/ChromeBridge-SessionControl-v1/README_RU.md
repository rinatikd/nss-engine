# Chrome Bridge — Session Control v1

Цель: сохранить **явно выданный** Grant control при перезапуске cutover-сервера и обновлении управляющей вкладки, пока не истекли 60/180/240 минут. Не делать бессрочного автодоступа.

Изменяется **только** `C:\Engineering\chrome-bridge\extension\control.js`; сервер, `page.js`, токены и конфигурация остаются без изменений. Проверяются исходные фрагменты; если они отличаются, установка прекращается без записи. На успешной установке создаётся резервная копия, проверяется `node --check`.

## Установка

Распаковать ZIP. В PowerShell:

```powershell
$installer = Get-ChildItem 'C:\Engineering\chrome-bridge\codex-handoff-output' -Recurse -Filter 'Install-SessionControl.ps1' -File | Select-Object -First 1 -ExpandProperty FullName
Unblock-File -LiteralPath $installer
& $installer -VerifyOnly
& $installer
```

После `PATCHED_SESSION_CONTROL_RELOAD_EXTENSION` обновить расширение в `chrome://extensions`, открыть панель Chrome Bridge и нажать «Подключить». **Один раз заново выдать Grant control** для нужных сайтов: уже выданные *ранее* разрешения не могут быть восстановлены из старого volatile Map. После этого при перезапуске сервера в пределах оставшегося срока повторный Grant control не нужен. Если панель управления закрыта, её потребуется открыть и подключить — патч не включает автостарт соединения.

## Сохранённые ограничения

- Chrome-session storage, не disk-local; не переживает полноценный перезапуск Chrome.
- Явная выдача пользователем, ограниченный TTL и allowlist AI origins.
- При ручном «Остановить» сохранённые разрешения отзываются.
- При удалении сайта или изменении origin разрешение отзывается.
- Не изменяются подтверждения опасных действий или запрет секретов.

## Откат

Остановить работу расширения; заменить `extension\control.js` созданной резервной копией, затем Reload расширения. Не менять сервер.

## Ограничения проверки

Проверка выполнена на доступной версии `control.js` из более раннего архива; фактический текущий `control.js` проверяется установщиком на совместимость. Интеграционный тест Windows/Chrome выполняется после установки. Если `SOURCE_MISMATCH`, **не обходить** проверку, нужен актуальный `control.js`.
