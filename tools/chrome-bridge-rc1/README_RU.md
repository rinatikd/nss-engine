## Применение обновления

Из корня полученного репозитория, Node.js >=22:

```powershell
node tools/chrome-bridge-rc1/apply-update.mjs --source "C:\путь\распакованный-архив\chrome-bridge" --output "C:\путь\новый-кандидат-rc1"
```

Исходная папка не меняется. Если хоть один из исходных файлов отличается,
установщик останавливается до создания результата. В этом случае возьмите
свежую распаковку исходного ZIP; не удаляйте собственные изменения. Неописанные
локальные файлы, включая приватные настройки, не копируются. Вывод должен быть
новой папкой вне исходников и пакета обновления. Не выполняйте установку из
каталогов, перенаправленных символическими ссылками/junction.

Из папки кандидата:

```powershell
node --test tests/*.test.mjs
```

Затем откройте `RELEASE_CANDIDATE_RU.md`. Регистрация MCP предварительно
просматривается; применение выбирается явно. Уже существующую регистрацию
помощник не заменяет. Если обновляется действующая установка, отдельно
сохраните регистрацию и настройте откат, прежде чем переключать её.

## Что остаётся до финала

Настоящая Windows-проверка, загрузка расширения, проверка Stop/revoke/replay,
реальный обмен с каждым заявленным сайтом. Для ChatGPT app нужна отдельная
проверка внешнего подключения; stdio-регистрация Codex его не создаёт. Для
запуска Codex через Bridge требуется подтверждённая изоляция, пока он выключен.
Эта версия — кандидат, а не подтверждённый production-релиз.
