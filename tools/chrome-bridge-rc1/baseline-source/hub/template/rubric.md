# Рубрика оценки (0–10)
- 9–10: полностью соответствует критериям, нет дефектов, можно выпускать.
- 8: мелкие недочёты, не влияющие на работоспособность и смысл. Порог приёмки по умолчанию.
- 5–7: есть существенные пропуски или ошибки; нужна доработка.
- 0–4: не соответствует заданию.
Любая ошибка безопасности, выдуманные факты/API или нарушение формата — не выше 6.
