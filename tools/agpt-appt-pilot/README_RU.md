# AGPT/APPT — первая рабочая задача Chrome Bridge RC2

Это исходный патч `1.1.0-preview.2` → `1.1.0-preview.3`, а не полный дистрибутив.
В нём 11 файлов: guard APPT_ZONE, правила разметки и их тесты, механизм
владения выходом полного альбома, интеграция и номера версии. Бинарники,
эталонные DWG/PDF и приватные данные сюда не входят.

Исходная preview.2 ранее существовала в облачной рабочей копии, но её наличие
на основном ПК не подтверждено. Патч нельзя слепо применять к v1.0 или иной
версии. Восемь прежних файлов перечислены в `PREVIEW2_BASE_SHA256SUMS.txt`;
три новых файла должны отсутствовать. Проверить базовые хеши и отсутствие новых
файлов, затем в отдельной копии проекта выполнить `git apply --check` с путём
к `preview2-to-preview3.patch`. Если база не совпадает, локальный Codex должен
сопоставить изменения с актуальной версией, сохранив её собственные правки.

Патч проверен применением к чистой preview.2: все 11 результирующих файлов
побайтово совпали с проверенной preview.3. Отчёт: [TEST_REPORT_RU.md](TEST_REPORT_RU.md).
Применение патча само по себе не подтверждает работу AutoCAD и не устанавливает DLL.

Для настоящего пилота через RC2 локальный Codex должен выполнить
[задание](../../docs/AGPT_APPT_RC2_PILOT_20261030.md): связать вкладку Claude,
получить одну содержательную рецензию с фиксированным requestId и проверить её.
Внутренние помощники облачной беседы уже провели ревью; это не выдаётся за
вызов Claude через Bridge.
