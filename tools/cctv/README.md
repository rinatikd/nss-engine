# Сборка СВН v09

Сохранены последние авторские скрипты построения v09 и углового варианта, ранее находившиеся во временном каталоге. Корень проекта теперь определяется относительно файла. Это промежуточный инженерный pipeline, а не универсальный генератор без исходных данных.

Требуются локальные закрытые входы: исправленный DXF ТКК в корне; `output/CCTV_v08_review/plot_geometry.json`, `review_v08.json`, `CCTV_Source_v08_review.dxf`. Сначала `python tools/cctv/plan_thermal_chain.py`, затем `build_package_v09.py`, затем `finalize_package_v09.py`. Все эти входы и выходы исключены из Git. До запуска проверь наличие входов и сделай отдельную копию задания. Код не подтверждает нормативное покрытие, монтажную высоту или стоимость. `ezdxf`, `shapely`, `scipy` устанавливаются в локальную среду отдельно.

Основной вариант сохраняет 34 ТВ и 11 шкафов; 47 ТВ и 12 шкафов — отдельное несогласованное предложение для поворотов. Новые собственные опоры исключены: обычные камеры/шкафы — на существующих опорах освещения, ТВ — снаружи на ограждении. Штриховки секторов ANSI31, scale 4. Исходный слой ТКК сохраняется и проверяется по DXF-тегам.

После совместной проверки 24.10.2026 сектор использует дополнительные лучи к вершинам ограждения и по обе стороны от них: прежнее соединение только равномерных лучей могло включать тень за углом. Расчёт остаётся приближённым 2D: дуга дальности аппроксимирована хордами, угловой допуск — 1e-7 рад, отступ перед препятствием — 1 мм. Контроль сохранности ТКК дополнительно проверяет определения блоков, достижимых по INSERT, включая вложенные блоки и базовые точки; содержимое внешних файлов и зависимые таблицы этим контролем не проверяются.

Новые проверки работают на синтетических данных через `python tools/run_portable_checks.py`. Реальные комплекты DXF/SVG/PNG и проценты покрытия в прежних отчётах в этом цикле не пересобраны; обновление кода не означает обновление выданных чертежей. Подробности и результаты приёмки — в `docs/MULTI_AGENT_REVIEW_2026-10-24.md`.
